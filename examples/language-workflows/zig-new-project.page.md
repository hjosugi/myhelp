# Zig new project

> Create and maintain a Zig project with its built-in build system.
> Official documentation: <https://ziglang.org/learn/build-system/>.

- Initialize a project in a new directory:

`mkdir {{project}} && cd {{project}} && zig init`

- Build the default install step:

`zig build`

- Run the generated application:

`zig build run`

- Run the project's test step:

`zig build test`

- Format all Zig source files:

`zig fmt .`
